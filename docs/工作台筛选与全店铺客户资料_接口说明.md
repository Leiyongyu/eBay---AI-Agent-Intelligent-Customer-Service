# 工作台筛选项与全店铺客户资料：接口说明（给前端）

后端已实现并通过测试（`tests/test_list_filters.py`）。前端只需要把这些参数接到筛选面板和右侧面板上。

## 1. 列表筛选：`GET /internal/conversations`

原有参数不变（`group`、`view`、`kind`、`q`、`store_id`、`tag_id`、`stage`、`unread_only`、`read_only`）。**新增参数（都可组合，服务端过滤）**：

| 筛选项（截图） | 参数 | 说明 |
|---|---|---|
| 客户ID（多个用回车或逗号分隔）+ 开头 | `buyers`、`buyer_match` | `buyers` 逗号 / 换行分隔；`buyer_match` = `contains` 包含（默认）/ `prefix` 开头 / `exact` 完全一致；不区分大小写，下划线按字面匹配 |
| eBay账号（= 店铺名） | `store_ids` | 店铺 ID，逗号分隔（多选）；下拉候选见第 3 节 `stores` |
| 站点 | `site` | 如 `EBAY_DE` |
| ★ 星标 | `starred=true` | 只看星标；标星见第 2 节 |
| 订单编号 | `order_no` | 按本地订单汇总对到买家，或消息里提到这个订单号、查件单的订单号 |
| 货运单号 | `tracking_no` | 查件单的跟踪号 → 订单 → 买家，或消息里提到这个单号 |
| 库存SKU / 平台SKU | `sku` | eBay 订单里的 SKU（自定义标签）；目前两个筛选项都用这个参数（谷仓库存 SKU 与 eBay SKU 一般相同） |
| 标签 | `tag_ids` | 标记 ID，逗号分隔，有任一即可 |
| 消息类型 | `kind` | 原有：`buyer` 买家消息 / `system` eBay 平台消息 |
| 最近回复人 | `last_replier` | 发出最后一条店铺消息的人：客服名、`AI（自动回复）`（即 AUTO_ACTOR）、`eBay 后台`（直接在 eBay 后台回复的） |
| 草稿 | `draft` | `has` 有 AI 草稿 / `none` 没有 |
| 负责人 | `assignee` | 认领人显示名；`unassigned` = 没人认领 |
| 消息内容 / 消息检索 | `content` | 在会话全部消息的原文和中文译文里模糊搜 |
| 最初消息时间 | `first_from`、`first_to` | 会话第一条消息时间范围，ISO 日期或时间（UTC），格式错 422 |
| 最新消息时间 | `last_from`、`last_to` | 同上，按最新消息时间 |
| 售后情况 | `group` | 原有：`aftersales` 待售后 / `aftersales_done` 售后已完成 / `invoice` 待发发票 |

列表每项新增字段：`starred`（是否星标）、`last_replier`（最近回复人）、`blacklist`（黑名单信息或 null）。

注意：列表仍是最多 300 条（按最新消息时间）；负责人、草稿、最近回复人是在这 300 条里再过滤。

## 2. 星标：`PUT /internal/conversations/{id}/star`

请求 `{"starred": true|false}`，返回 `{"id", "starred", "starred_by"}`。星标同事共用。会话详情 `conversation` 外层也带 `starred`、`starred_by`。

## 3. 筛选下拉候选：`GET /internal/conversations/filter-options`

```json
{
  "stores": [{"id": "ZN-…", "name": "pieces_saleshop", "marketplace_id": "EBAY_DE"}],
  "sites": ["EBAY_DE", "EBAY_GB", "EBAY_US"],
  "assignees": ["客服小王", "…"],
  "repliers": ["客服小王", "…", "AI（自动回复）", "eBay 后台"],
  "tags": [{"id": 1, "name": "查适配中", "color": "primary"}],
  "buyer_match": [{"value": "contains", "label": "包含"}, {"value": "prefix", "label": "开头"}, {"value": "exact", "label": "完全一致"}]
}
```
`stores` 按当前账号的店铺范围；“eBay账号”下拉显示 `name`，传 `id`。

## 4. 右侧“客户资料 / 历史记录”覆盖全部店铺：`GET /internal/conversations/{id}/customer`

原有字段不变（`profile`、`orders` 仍是实时查的当前店铺订单；`history` 是同一买家在我能看的店铺里的其他会话）。**新增 `all_stores`**：这个买家在当前账号能看的**全部店铺**的订单汇总（本地 `ebay_orders`，37 个店铺近 180 天，每小时增量更新）：

```json
"all_stores": {
  "buyer": "westdrayto0",
  "order_count": 3,
  "amounts": {"GBP": 42.5, "EUR": 20.0},
  "stores": [{"store_id": "ZN-…", "store_name": "Moses-motorsports", "orders": 2, "amounts": {"GBP": 42.5}}],
  "first_order_at": "2026-06-01T10:00:00Z", "last_order_at": "2026-10-28T21:01:20Z",
  "refunded_orders": 1, "cancelled_orders": 0,
  "returns": 1, "disputes": 0, "negative_feedback": 0,
  "orders": [{"store_id": "ZN-…", "store_name": "…", "order_id": "17-15341-85395", "created_at": "…",
              "total": 14.16, "currency": "GBP", "status": "FULFILLED", "item_id": "…", "item_title": "…",
              "skus": "RNG-80034-0723", "refunded": false, "cancelled": false}],
  "orders_synced_days": 180
}
```
建议：“客户资料”页签的累计订单、金额、店铺分布、首末单、退款取消、退货纠纷差评改用 `all_stores`；“历史记录”页签在会话列表之外加一段“全部店铺的订单”（`all_stores.orders`，最多 100 单，新的在前）。
